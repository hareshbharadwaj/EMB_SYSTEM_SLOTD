# Embedded Systems Experiments

Arduino and ESP32 experiment source code is stored in the individual experiment folders. Available source folders: EXP1–EXP4, EXP13–EXP17, EXP19 and EXP20.

See [OUTPUT_SCREENSHOTS](../OUTPUT_SCREENSHOTS/README.md) for available reference screenshots. These are linked from the supplied reference repository and are not claimed as fresh test results from these sketches.

The reference repository contained only empty README files for EXP5, EXP6, EXP10, EXP11 and EXP12, so no unverified code has been added for those numbers.
